# RyuLink-Atmosphere

RyuLink-Atmosphere is an **unofficial community-maintained distribution repository** used to provide versioned Atmosphère-related packages for installation and compatibility testing with RyuLink MTP.

> This repository is not an official Nintendo or Atmosphère distribution channel.

## Project scope

- Provides versioned release packages for convenient download and installation.
- Intended for compatibility testing, maintenance and legitimate homebrew use on hardware you own.
- Release tags in this repository may refer to the **target Nintendo Switch system version / compatibility target** and do not necessarily represent the upstream Atmosphère version.
- RyuLink does not claim ownership of third-party projects contained in release archives.

Before installation:

- back up important SD-card data;
- confirm the package matches the intended system/compatibility version;
- do not interrupt the device or remove storage during an active write operation.
